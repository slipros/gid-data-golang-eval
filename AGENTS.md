# Инструкции для агентов

## Выпуск релиза

После публикации нового релиза самостоятельно установи выпущенную версию CLI
и очисти кэш линтера:

```sh
go install github.com/slipros/gid-data-golang-eval/cmd/custom-gcl@<тег-релиза>
custom-gcl cache clean
```

Это часть выпуска релиза; не перекладывай выполнение команд на пользователя.
