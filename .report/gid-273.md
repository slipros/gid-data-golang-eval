# GID-273 — closure-ctor (линтер `gidclosurector`)

## Суть правила

Функция или метод, который **собирает и возвращает замыкание**, — встроенный конструктор
этого замыкания, и по GID-104 носит префикс `New`/`new`.

Повод (требование владельца 2026-08-27, consent-webhook-trigger):

```go
func (w *WebhookTriggerV2) contactFilter(
    scope model.WebhookTriggerV2ContactFilterScope,
) func(identifier *model.ConsentEventV2UserIdentifier) bool
```

Метод не возвращает ничего доменного — он собирает предикат и отдаёт его. Значит,
`newContactFilter`: на месте вызова читается, что вещь строится, а не достаётся.

## Что судится

Оба условия сразу:

1. в списке результатов есть **функциональный тип** — голый `func(...)` или именованный
   тип над ним (`model.Predicate`);
2. тело **действительно строит** эту функцию: возвращается функциональный литерал —
   напрямую или через локальную переменную, связанную с литералом.

Второе условие отделяет конструктор от **аксессора**: `return w.filter` отдаёт ранее
собранный колбэк и не судится, `return func(...) bool { … }` делает его на месте.
Литерал, вложенный в другое замыкание, принадлежит тому замыканию, а не судимой функции
(обход не спускается внутрь `*ast.FuncLit`).

## Что НЕ судится

- Имя уже с префиксом `New`/`new` — это и есть фикс. Префикс проверяется как **целое
  слово**: `newest` судится.
- Конвенция опций (GID-126): функция с префиксом `With`, и любая функция, чей результат —
  именованный тип с суффиксом `Options`/`Option`/`Opt`. `settings.option-suffixes`
  заменяет список.
- `_test.go` (GID-250): хелпер, возвращающий cleanup-функцию (`setup() func()`), назван
  тестовой конвенцией.
- Сгенерированный код.

Исключения: `//nolint:gidclosurector`, `settings.exclude` (`Function` | `Type.Method`).

## Реализация

- `analyzers/closurector/analyzer.go` — обход через `astwalk.NodesOf[*ast.FuncDecl]`,
  load mode `TypesInfo` (именованный тип над `func` распознаётся через `types.Signature`);
  обход тела — `ast.Inspect`, сужённый до одного тела функции, как велит конвенция.
- Сообщение называет готовое имя: `contactFilter` → `newContactFilter`, экспортированная
  `ScopePredicate` → `NewScopePredicate`.

## Eval

`analysistest` + `// want`, четыре класса:

- **позитив**: форма инцидента дословно (метод с scope → предикат по идентификатору),
  литерал через локальную переменную, экспортированный билдер (проверяет регистр
  предлагаемого имени), литерал из ветки `if`;
- **негатив**: `newContactFilter`/`NewScopePredicate`, аксессор `Filter()` отдающий поле,
  функция без функционального результата;
- **граница**: `WithRetry` с голым функциональным результатом (исключает только префикс),
  `retryOption` с типом `SendOption` (исключает только суффикс), `newest` (префикс —
  целое слово), `passthrough` (литерал принадлежит вложенному замыканию);
- **неприменимость**: `_test.go`, сгенерированный файл, `settings.exclude` в обеих формах,
  `settings.option-suffixes`, заменяющие дефолт.

Мутационная проверка различимости (каждая правка краснит eval, откат — зелёный):
снятие проверки «тело строит замыкание», снятие обрезки вложенных литералов, снятие
исключения `With`, снятие исключения по суффиксу опций.

## Осознанно оставленное

- Правило действует во всех слоях, не только в `/domain/**`: конструктор замыкания
  одинаково читается везде. Библиотечные формы, где имя задано чужой конвенцией
  (gRPC-интерцептор, middleware-фабрика), гасятся `//nolint` или `settings.exclude`.
- Возврат замыкания, собранного вызовом другой функции (`return s.buildFilter()`),
  не судится — эта функция строит не здесь.
- Замер по репозиториям udmp не делался.
