# GID-272 — лимит аргументов в доменном слое (linter `gidarglimit`)

## Суть правила

Функция или метод в `/domain/**`, принимающая больше 3 содержательных аргументов, — нарушение:
функция перестала быть преобразованием и стала сборкой; её надо разбивать или вводить тип,
несущий связанные поля.

Повод (требование владельца 2026-08-27): `WebhooksTriggersV2FromConsentEventV2` в
consent-webhook-trigger принимает шесть аргументов, из них четыре — мапы по одному и тому же
ключу `organizationID` (четыре мапы — одна сущность: события одной организации).

## Что судится

- Пакеты внутри `/domain/**` на любой глубине — `internal/domain/...` и `pkg/<module>/domain/...`.
  Слой определяется через `internal/pathseg.HasLayer(path, "domain")` по сегментам пути.
- Функции пакетного уровня и методы. Ресивер аргументом не считается.
- Число параметров по именам: `func f(a, b int, c string)` — три аргумента; безымянный параметр —
  один; вариадический хвост — один аргумент.

## Что НЕ судится

- Конструкторы — префикс `New`/`new` (граница GID-104, тот же `isCtorName`, что у GID-268).
- `context.Context` — параметр технический, в счёт не идёт (решение владельца; распознаётся по
  типу `types.Named` с pkg path `context` / name `Context`).
- `_test.go` — не судится (конвенция GID-250, `srcfile.IsTest`, как у GID-260/261).

## Порог и настройки

- Дефолт: 3 разрешённых аргумента, нарушение с 4.
- `settings.max-args` — настраиваемый порог (`0` → дефолт 3).
- Исключения: `//nolint:gidarglimit` и `settings.exclude` в форме `Function` | `Type.Method`
  (механизм `internal/exclude`, как у GID-247/261).

## Реализация

- `analyzers/arglimit/analyzer.go` — обход через `internal/astwalk.NodesOf[*ast.FuncDecl]`
  (не `ast.Inspect`), `Requires: astwalk.Requires`; load mode — `LoadModeTypesInfo`
  (нужен `pass.TypesInfo` для распознавания `context.Context`).
- `analyzers/arglimit/arglimit.feature` — спека по шаблону `rule_template.feature`.
- Eval: `analysistest` + `testdata/src/...` с `// want`, четыре класса кейсов:
  - **позитив**: 4 аргумента, метод с 4, вариадический хвост (3+хвост = 4), инцидентный шейп
    (4 мапы по одному ключу), инцидент `WebhooksTriggersV2FromConsentEventV2` (6 аргументов)
    в layout `pkg/<module>/domain/...`, безымянные параметры;
  - **негатив**: 0..3 аргумента, 3 аргумента + ctx;
  - **граница**: ровно 3 — чисто, ровно 4 — нарушение, 3 + ctx — чисто;
  - **неприменимость**: конструктор (`New*` и `new*`), `_test.go`, файл вне `/domain/**`
    (`svc/dal/entity`), `settings.exclude` (Function и Type.Method), кастомный порог
    (`max-args: 1`).

## Гейты

## Смоук-тест собранного бинаря

Временный модуль с `/internal/domain/service`:

- `Svc.TooMany(ctx, a, b, c, d)` — 4 содержательных (ctx исключён) → диагностика;
- `Svc.Fine(ctx, a, b, c)` — 3 → чисто;
- `ConvertSix(a..f)` — 6 → диагностика;
- `NewService(a..e)` — конструктор → чисто;
- `settings.max-args: 5` + `exclude: [ConvertSix]` → 0 issues.

Замер по внешним репозиториям (six udmp) делает супервизор после сборки — их деревья не
смонтированы.
