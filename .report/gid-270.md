# GID-270 — model-place («модель данных объявляется только в /domain/model»)

Линтер: `gidmodelplace`, ID `GID-270`. Ветка `feat/GID-270-model-place` (от `main`).

Постановка: owner requirement 2026-08-27 — «Не может convert возвращать какую-то
бизнес сущность. Бизнес сущности объявляются только в пакете model»; «Все модели
данных живут только в domain/model. Не могут они вот так просто объявляться
в service, usecase, convert». Повод: `WebhookTriggerV2Build` в пакете `convert`
и `AltCraftTriggerV2Build` прямо в `usecase` (consent-webhook-trigger).

## Что сделано

- `analyzers/modelplace/analyzer.go` — обе части одним линтером:
  - **Часть A** — в пакете, чей последний сегмент пути `convert`
    (`pathseg.EndsWith`, та же граница, что у GID-247), структуры не
    объявляются вовсе; только объявления структур (интерфейс/именованный
    basic-тип — вне зоны). Сообщение называет выход: «declare the type in
    /domain/model». Пакет `convert`, вложенный в `/domain` (`usecase/convert`,
    `repository/convert`), судится частью A и НЕ дублируется частью B.
  - **Часть B** — в `/domain/service` и `/domain/usecase`
    (`pathseg.HasLayer` по сегментам, работает и для `internal/domain/...`,
    и для `pkg/<module>/domain/...`) экспортированная структура — модель
    данных, если выполнено ВСЁ: у типа нет методов в пакете; тип не
    возвращается ни одной функцией с префиксом `New`/`new` в пакете
    (результат по указателю тоже считается — через `types.Named`); имя не
    оканчивается на суффикс опций (`settings.suffixes`, дефолт
    `Options`/`Option`/`Config`/`Params`/`Settings`).
  - Общие границы: `_test.go` не судится (`internal/srcfile.IsTest`),
    сгенерированный код не судится (`ast.IsGenerated`), неэкспортированные
    типы не судятся в обеих частях.
  - Обход AST — через `internal/astwalk` (`NodesPruning` c обрезкой тел
    функций: тела не содержат пакетных объявлений), `Requires:
    astwalk.Requires`; никаких `ast.Inspect`.
  - Исключения: `//nolint:gidmodelplace` и `settings.exclude` в форме
    `Struct` (как у GID-260).
- `analyzers/modelplace/modelplace.feature` — спека (шаблон `rule_template.feature`).
- `analyzers/modelplace/analyzer_test.go` + `testdata/src/...` — eval.
- `plugin.go` — регистрация `gidmodelplace` (configurable, LoadModeTypesInfo).
- Включён в оба встроенных конфига: `gid-golangci.yml` и
  `gid-golangci-rules.yml` (гейты `TestDefaultConfigEnablesRegisteredLinters`,
  `TestBuiltinConfigsShipEveryRegisteredLinter`, `TestRulesOnlyConfigMatchesDefault`).
- `.golangci.yml` — референсный конфиг: строка в `linters.enable` + блок
  в `linters.settings` с `desc` и примером настроек.
- `RULES.md` — строка реестра (раздел «Types and fields», после GID-269).

## Eval

`analysistest` + `// want`, все четыре класса:

- **позитив**: часть A — структура в `mp/convert` и в `mp/domain/usecase/convert`
  (последняя — ровно один диагностик, не два); часть B —
  `TriggerBuild`/`Permissions` в `/domain/service`, `AltCraftTriggerBuild` в `/domain/usecase`;
- **негатив**: `/domain/model` (каноническое место), пакет вне `/domain/**`
  (`/server/http`), пакет `convert` без объявлений типов;
- **граница** (каждое исключение): структура с методом (`Processor.Run`),
  структура от конструктора с указателем (`NewIntegration → *Integration`),
  с value-результатом (`NewReport() Report`), с префиксом `new`
  (`newPair → *Pair`), все пять суффиксов опций по умолчанию
  (`ServerOptions`, `SendOption`, `JobConfig`, `QueryParams`, `SyncSettings`);
- **неприменимость**: `_test.go` (`TestHarness`), неэкспортированный тип в
  обеих частях (`draft`, `kind`), не-структура в `convert` (`Kind string`,
  `Mapper interface`), сгенерированный код (`gen.go`).
- Настройки (`TestAnalyzerSettings`, пакет `custom/…`): `settings.suffixes`
  заменяет дефолт (структура `LegacyOptions` с кастомным `["Spec"]`
  репортится), `settings.exclude` в форме `Struct` действует на обе части
  (`LegacyDTO`, `Exempt`).

Мутационная проверка различимости: выключение проверки конструктора
(`builtByCtor`) краснит eval; восстановление — снова зелёный.

## Осознанно оставленное

- Конструкторы учитываются только на уровне пакетных функций (не методов с
  `New`-префиксом) и только по результату-типу/указателю на тип (не
  слайсы/мапы) — в замере супервизора (34 → 2+1) такие формы не встречались.
- Часть A судит только структуры («судятся объявления структур»);
  интерфейсы и именованные basic-типы в `convert` — вне правила.
